# CA-сертификаты для источников данных

## Росказна (roskazna.gov.ru)

Сайт Федерального казначейства отдаёт TLS-цепочку, подписанную корнем
**«Russian Trusted Root CA»** (Минцифры). Этого корня нет ни в системном
хранилище macOS/Linux, ни в бандле `certifi`, и он там не появится — поэтому
`urlopen` падает с `CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate`.

Фактическая цепочка источника:

```
roskazna.gov.ru
  └── Russian Trusted Sub CA        (отдаётся сервером)
        └── Russian Trusted Root CA (нужно добавить локально)
```

Промежуточный Sub CA сервер присылает сам, не хватает только корня.

### Как включить проверку

1. Получите PEM корневого сертификата «Russian Trusted Root CA» из официального
   источника Минцифры.
2. **Сверьте отпечаток** (SHA-256) с опубликованным на официальном ресурсе —
   до того, как положить файл в проект. Добавление корневого CA расширяет круг
   доверия, поэтому шаг обязателен:
   ```bash
   openssl x509 -in russian_trusted_root_ca.pem -noout -fingerprint -sha256
   ```
3. Положите файл сюда как `certs/russian_trusted_root_ca.pem` — загрузчик
   подхватит его автоматически. Либо укажите свой путь:
   ```bash
   export ROSKAZNA_CA_BUNDLE=/путь/к/бандлу.pem
   ```

Проверить, что бандл виден:

```bash
.venv/bin/python -m backend.src.downloaders.roskazna_treasury_deposits_downloader --years 2026
```

### Чего этот бандл НЕ лечит

Проверка сертификата состоит из двух независимых условий, и корень закрывает
только первое:

- **доверие к issuer** — лечится бандлом;
- **срок действия сертификата сервера** — не лечится ничем на нашей стороне.

На 30.07.2026 сертификат `roskazna.gov.ru` истёк 28.07.2026 14:42 UTC. Пока
Казначейство не перевыпустит его, проверка будет падать с
`certificate has expired` даже при корректно установленном корне. Это ожидаемое
поведение: истёкший сертификат неотличим от подменённого, и обходить проверку
для источника, кормящего казначейскую модель, нельзя.

Прежний код в такой ситуации молча уходил на `ssl._create_unverified_context()`.
Этот путь убран.
